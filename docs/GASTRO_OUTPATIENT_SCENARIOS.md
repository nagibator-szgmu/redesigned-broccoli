### Маршрутизация (как видит игрок в интерфейсе)

На этапе «Диагноз и маршрутизация» игрок видит форму ввода диагноза и блок из **4 кликабельных карточек выбора тактики**:

1. 🔘 `[Иконка Врача]` **«Направить на консультацию к хирургу для планового оперативного лечения»**  
   *(Внутренний ID: `refer_specialist`. ВЕРНЫЙ ВЫБОР).*  
   *Обоснование для дебрифинга:* Верно! Симптомная ЖКБ (задокументированные приступы колик при подтверждённом калькулезе) — прямое показание к плановой лапароскопической холецистэктомии в «холодном» периоде (КР 877/1, УУР А, УДД 1).
2. 🔘 `[Иконка Рецепта]` **«Оставить под амбулаторным наблюдением терапевта без консультации хирурга»**  
   *(Внутренний ID: `treat_outpatient`. ОШИБКА).*  
   *Обоснование для дебрифинга:* Ошибка. При симптомной ЖКБ консервативная тактика опасна рецидивами колик, вклинением конкремента, острым холециститом и механической желтухой.
3. 🔘 `[Иконка Стационара]` **«Плановая госпитализация в терапевтическое отделение»**  
   *(Внутренний ID: `refer_hospitalization`. ОШИБКА).*  
   *Обоснование для дебрифинга:* Нерационально. Терапевтическое отделение не решает проблему калькулеза.
4. 🔘 `[Иконка Скорой]` **«Вызов СМП для экстренной госпитализации в хирургический стационар»**  
   *(Внутренний ID: `call_ems`. ОШИБКА).*  
   *Обоснование для дебрифинга:* Необоснованно. Острый холецистит и перитонит исключены, приступ купирован, показаний для экстренной госпитализации нет.

---

### Фармакотерапия
- **Обоснованное лечение (`needTreat`):** Спазмолитики (`spasmolytics` — миотропные спазмолитики per os: дротаверин, мебеверин).
- **Опасные назначения (`wrongTreat`):**
  - **Морфин (`morphine`):** Вызывает спазм сфинктера Одди и резкий подъём внутрипузырного давления, провоцируя рецидив колики.
  - **Аспирин (`aspirin`):** Повреждает слизистую желудка (в анамнезе гастрит) и нежелателен перед операцией.
  - **Тромболизис (`thrombolysis`):** Смертельно опасен кровотечениями.

### Анамнез заболевания (Anamnesis morbi)

### Маршрутизация (как видит игрок в интерфейсе)

На этапе выбора тактики игроку предлагаются **4 карточки выбора**:

1. 🔘 `[Иконка Рецепта]` **«Амбулаторное лечение: селективные спазмолитики per os, диета Low-FODMAP и ведение дневника питания»**  
   *(Внутренний ID: `treat_outpatient`. ВЕРНЫЙ ВЫБОР).*  
   *Обоснование для дебрифинга:* Верно! СРК — функциональное расстройство.    *(Внутренний ID: `refer_specialist`. ОШИБКА).*  
   *Обоснование для дебрифинга:* Ошибка. СРК не является хирургической патологией, показаний к операции нет.
3. 🔘 `[Иконка Стационара]` **«Плановая госпитализация в гастроэнтерологическое отделение стационара»**

   *Обоснование для дебрифинга:* Необоснованно. Диагностический поиск завершён амбулаторно, показаний для круглосуточного стационара нет.
4. 🔘 `[Иконка Скорой]` **«Экстренная госпитализация бригадой СМП в инфекционный стационар»**  
   *(Внутренний ID: `call_ems`. ОШИБКА).*  
   *Обоснование для дебрифинга:* Ошибка. Острая кишечная инфекция исключена (анамнез 7 месяцев, нормальная температура, нормальный СРБ, отсутствие ночной диареи).

### Фармакотерапия
- **Обоснованное лечение (`needTreat`):** Селективные спазмолитики (`spasmolytics` — мебеверин, отилония бромид per os для нормализации моторики и висцеральной чувствительности).
- **Опасные назначения (`wrongTreat`):**
  - **Антибиотики широкого спектра (`antibiotics_broad`):** Провоцируют выраженный дисбиоз и усиление диареи при функциональном СРК.
  - **Фуросемид (`furosemide`):** Противопоказан, вызывает дегидратацию и гипокалиемию при диарейном синдроме.
  - **Аспирин (`aspirin`):** Повреждает слизистый барьер кишки.
