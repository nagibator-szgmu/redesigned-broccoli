# РЕВИЗИЯ И СПЕЦИФИКАЦИЯ SVG-ИКОНОК ДЛЯ MEDSIM (ПАКЕТ ДЛЯ CHATGPT)

**Проект:** MedSim (Клинический симулятор скорой помощи, реанимации, стационара и поликлиники)  
**Стек:** React (JSX), Vite, без сторонних иконочных библиотек (чистый SVG)  
**Цель:** Полная перегенерация файла `src/ui/icons.jsx` для создания унифицированной векторной системы из 72 иконок.

---

## 1. Контекст задачи и архитектурные требования

В симуляторе MedSim все иконки реализованы как нативные React-компоненты в файле `src/ui/icons.jsx`.
Сейчас в системе есть две большие проблемы:
1. **Визуальный разнобой существующих 50 иконок:**
   - Часть иконок нарисована грубо и анатомически неверно (`IconAbdominal` — круг с плюсом, `IconNeuro` — спицы прицела, `IconToxicology` — смайлик с зашитым ртом, `IconEndocrine` — химическая колба).
   - Часть иконок имеет сплошную заливку (`IconPlay`, `IconPause`), в то время как весь остальной интерфейс построен на тонких контурных линиях (stroke).
   - Различается толщина линий (встречаются `1.5px` и `2.0px`), случайные параметры прозрачности (`opacity="0.4"`).
2. **Слепые зоны интерфейса (более 80 мест с эмодзи и текстовыми стрелками):**
   - В кодовой базе используются эмодзи: `💉` (шприц), `🧪` (пробирка), `🚨` (сирена), `⚡` (дефибрилляция/пульс), `🛡️` (клинические рекомендации), `✨` (перфекционист), `⭐` (рейтинг), `🚶` (маршрут поликлиники), `📄` (выписка), `⚖️` (шкала SOFA), `👁️` (зрачки ШКГ), `💊 Печень`, `Почки`.
   - Используются текстовые стрелки и символы: `←`, `→`, `▲`, `▼`, `✓`, `✕`.
   - В системе достижений (`src/data/certificates.js`) требуются иконки `sparkles` и `pulse`, но из-за их отсутствия отображался кубок.

## 2. Единые дизайн-токены векторной системы

Каждая иконка должна строго соответствовать следующим техническим параметрам:

1. **Размер холста (Canvas / viewBox):** Строго `0 0 24 24`.
2. **Безопасная зона (Live Area):** Внутренний квадрат `20x20` (отступы 2px с каждой стороны для оптического баланса).
3. **Базовый стиль:** "Medical-grade Minimalist Stroke" (в стиле Apple Health, Linear, Stripe и Lucide Pro).
4. **Толщина линий (Stroke Width):** Строго `2.0px` (параметр `strokeWidth={strokeWidth}`).
5. **Концы линий и углы:** `strokeLinecap="round"`, `strokeLinejoin="round"`.
6. **Заливка (Fill):** Строго `fill="none"` по умолчанию. Локальная заливка `fill={color}` допустима исключительно для мелких микро-точек (зрачок, капля, центр мишени).
7. **Цвет:** По умолчанию `color = "currentColor"`, `stroke={color}`.
8. **Сигнатура React-компонента:**
```jsx
export function IconName({ size = 20, color = "currentColor", strokeWidth = 2, className = "", style = {}, ...props }) {
  return (
    <svg
      width={size}
      height={size}
      viewBox="0 0 24 24"
      fill="none"
      stroke={color}
      strokeWidth={strokeWidth}
      strokeLinecap="round"
      strokeLinejoin="round"
      className={className}
      style={{ flexShrink: 0, display: "block", ...style }}
      {...props}
    >
      {/* векторы */}
    </svg>
  );
}
```
