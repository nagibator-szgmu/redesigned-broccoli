# Регламент работы агента Antigravity в MedSim

## 1. ОБЯЗАТЕЛЬНОЕ ИСПОЛЬЗОВАНИЕ MCP-СЕРВЕРОВ (MCP Tool Protocol)

У агента подключен стек настроенных MCP-серверов. Агент ОБЯЗАН активно использовать их в соответствующих сценариях, не забывая о них:

1. **`serena` (Семантический код-сервер и память проекта):**
   - Проект `redesigned-broccoli` активирован в Serena.
   - Использовать `find_symbol`, `get_symbols_overview`, `find_referencing_symbols`, `find_implementations` при рефакторинге и поиске функций вместо слепого grep.
   - Использовать `read_memory`, `write_memory` для фиксации архитектурных решений между сессиями.
2. **`context7` (Актуальная документация библиотек):**
   - Перед написанием сложных хуков React 18/19, Three.js или Vite обращаться к `context7` (`resolve-library-id`, `query-docs`) за эталонными сниппетами и документацией.
3. **`playwright` (Визуальный аудит и валидация интерфейса):**
   - При любых изменениях UI, редизайне или компоновке экрана результатов (`ResultScreen`) запускать `browser_navigate` и проверять отображение на экранах разной ширины (десктоп и мобильный вид).
4. **`github` & `git` (Контроль версий и веток):**
   - Использовать для проверки статуса, диффов, создания веток и работы с PR.
5. **`fetch` (Сетевые вызовы):**
   - Использовать для проверки внешних API, клинических рекомендаций или сервисов.
6. **`obsidian` (База знаний):**
   - Хранилище `Obsidian Vault` подключено для поиска заметок и контекста.

## 2. ПРОТОКОЛ ФИКСАЦИИ КОНТЕКСТА (Точки опоры)

1. **Файл-якорь `PROJECT_TRACKER.md`**:
   - В корне проекта ведется живой трекер всех шагов. Перед началом работы агент считывает текущий статус шагов, а по завершении — отмечает выполненные.
2. **Атомарные микро-шаги**:
   - Любое изменение делается микро-шагом (1-2 связанных файла).
   - После изменения обязательно: `npm run build` (0 ошибок) -> коммит с понятным сообщением -> обновление трекера.
3. **Запрет на перегруз файлов**:
   - Новые компоненты строго < 150-200 строк. Большие экраны обязательно декомпозируются на изолированные вкладки/виджеты.
