Интерактивный медицинский симулятор для студентов-медиков, ординаторов и врачей. Игрок берёт роль врача в одном из трёх отделений — приёмное/ОРИТ, поликлиника или стационар — и должен вести пациента от поступления до исхода в реальном времени.

## Как запустить

```bash
# Установить зависимости
npm install

# Запустить в режиме разработки
npm run dev
```

Откроется браузер на `http://localhost:3000`

```bash
# Собрать для продакшена
npm run build

# Предпросмотр сборки
npm run preview
```

Скопируйте `.env.example` в `.env` и настройте:


## Игровая механика

### Фазы игры

```
menu → order_tests → awaiting_results → diagnose → result
```

| Фаза | Что происходит |
|------|----------------|
| `menu` | Выбор кейса из списка, фильтрация по специальности |
| `order_tests` | Врач назначает обследования; пациент ухудшается в реальном времени |
| `awaiting_results` | Результаты приходят по одному (600–1000 мс); лечение можно назначать |
| `diagnose` | Врач ставит диагноз текстом и выбирает лечение |
| `result` | Детальный разбор: оценка, динамика виталов, пропущенные обследования |

### Таймер и ухудшение

- Пациент ухудшается каждые **30 секунд** (15 сек в стресс-режиме).
- Каждый кейс имеет вектор ухудшения (`deterioration`) — дельта на каждый тик.
- Если витал пересекает порог смерти (`deathThresholds`) — летальный исход.
- Лимит времени (`timeLimit`, в минутах) зависит от сложности.

## Клинические кейсы

**46 клинических случаев** по 7 специальностям и 3 отделениям:

| Специальность | Кейсы | Иконка |
|--------------|-------|--------|
| Кардиология | ОИМ, ХСН, АВ-блокада, тампонада, ФЖ | ❤️ |
| Неврология | Инсульт, менингит, эпилепсия, САК | 🧠 |
| Пульмонология | Пневмония, ХОБЛ, пневмоторакс, ОРДС, ТЭЛА | 🫁 |
| Инфекции | Сепсис, эндокардит, грипп, менингит | 🦠 |
| Эндокринология | ДКА, тиреотоксикоз | ⚗️ |
| Токсикология | Передозировка опиоидами, отравления | ☠️ |
| Хирургия | Панкреатит, внутрибрюшное кровотечение | 🔬 |

### Отделения

| Отделение | Кейсы | Особенности |
|-----------|-------|-------------|
| **Приёмное / ОРИТ** | 35 | Таймер, детериорация каждые 30 сек, экстренное лечение |
| **Поликлиника** | 6 | Без таймера, статичные виталы, структурированный диагноз + маршрутизация |
| **Стационар** | 5 | Посуточный цикл (утро → обследования → лечение → конец дня), критерии выписки |

### Структура кейса

```js
{
  id, name, age, gender,
  department,           // "emergency" | "outpatient" | "stationary"
  complaint,        // жалобы при поступлении
  vitals,           // начальные виталы: bp, hr, rr, temp, spo2
  initialGCS,       // начальный уровень сознания
  initialPain,      // начальный уровень боли (0–10)
  deterioration,    // дельта виталов каждые 30 сек (не для outpatient)
  deathThresholds,  // критические значения → летальный исход
  anamnesis,        // анамнез заболевания
  exam,             // данные физикального осмотра
  testResults,      // результаты обследований (объект id → текст)
  needDiag,         // обязательные обследования (для оценки)
  needTreat,        // обязательное лечение (для оценки)
  wrongTreat,       // противопоказанные препараты
  timeLimit,        // лимит времени в минутах
  tip,              // образовательная подсказка в разборе
  diagnosis,        // правильный диагноз (показывается в разборе)
  debrief,          // клинический разбор с патофизиологией
  // Поликлиника:
  correctRoute,     // правильный маршрут (ambulatory|specialist|planned_hospitalization|ems)
  routeOptions,     // [{id, label, description}]
  // Стационар:
  dayByDayPlan,     // [{day, morningStatus, tasks}]
  dischargeCriteria,// ["критерий1", "критерий2"]
  maxDays,          // лимит дней
}
```

## Система виталов

| Параметр | Ключ | Норма |
|----------|------|-------|
| Пульс | `hr` | 60–100 уд/мин |
| Систолическое АД | `sbp` | 100–140 мм рт.ст. |
| Диастолическое АД | `dbp` | 60–90 мм рт.ст. |
| Частота дыхания | `rr` | 12–20 /мин |
| Сатурация | `spo2` | 95–100% |
| Температура | `temp` | 36,5–37,5°C |
| Шкала Глазго | `gcs` | 15 |
| Боль (ВАШ) | `pain` | 0–10 |

Все виталы зажаты в физиологически достоверные диапазоны (`CLAMP_RANGES`).

## Диагностика и лечение

### Обследования (30 позиций)

Категории: кардио, лаборатория, дыхание, визуализация, нейро.

### Препараты и вмешательства (40 позиций)

Каждое лечение имеет:
- **`eff`** — эффект на виталы при правильном назначении
- **`delay`** — задержка до появления эффекта (в игровых секундах)
- **`desc`** — описание действия

**Противопоказания:** если препарат входит в `wrongTreat` кейса, применяются обратные эффекты (`ADVERSE_FX`) с клиническим обоснованием из `ADVERSE_REASONS`.

## Режимы игры

| Режим | Описание |
|-------|----------|
| **Обычный** | Стандартный режим с выбором кейса |
| **Случайный** | Случайный пациент без выбора |
| **Стресс** | ×2 скорость ухудшения, ×0.5 время |
| **Курс** | Поэтапное прохождение тем: теория → кейсы → тест. Темы разблокируются последовательно |

### Сложность

| Уровень | Множитель времени | Множитель ухудшения |
|---------|-------------------|---------------------|
| Лёгкая | ×1.5 | ×0.65 |
| Средняя | ×1 | ×1 |
| Сложная | ×0.7 | ×1.5 |

## Разбор после игры

1. **Оценка** (0–100) с грейдом: Отлично / Хорошо / Удовлетворительно / Неудовлетворительно
2. **Динамика виталов** — начало → финал + дельта
3. **Диагноз** — сравнение с правильным ответом
4. **Анализ обследований** — пропущенные критические тесты
5. **Анализ лечения** — назначенные, опасные, противопоказанные
6. **Патофизиология** — клинический разбор
7. **Хронология событий** — лог всех действий с временными метками

## Как добавить новый кейс

1. Открой appropriate файл в `src/data/cases/` (emergency/*.js, outpatient.js, stationary.js)
2. Скопируй любой кейс как шаблон
3. Поменяй `id`, `name`, `department`, `sourceReference`
4. Заполни клинические данные, `deterioration`, `deathThresholds` (для emergency)
5. Укажи `testResults` — объект, ключи совпадают с `id` из `DIAGNOSTICS`
6. Укажи `needDiag`, `needTreat`, `wrongTreat`
7. Для outpatient: добавь `correctRoute`, `routeOptions`
8. Для stationary: добавь `dayByDayPlan`, `dischargeCriteria`, `maxDays`
9. Добавь `diagnosisVariants: []`, `checklistItems: []`
10. Сохрани — barrel export подхватит автоматически

```bash
# Валидация всех кейсов
node scripts/validate-cases.mjs
```
