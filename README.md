## О проекте

**MedSim** — интерактивный симулятор клинического мышления для ординаторов терапевтического профиля, студентов 4–6 курсов медицинских вузов, врачей-стажёров и начинающих специалистов.

Платформа решает ключевой разрыв медицинского образования: переход от теоретического знания стандартов к принятию быстрых решений в условиях дефицита времени и неполных данных до контакта с реальным пациентом.

### Ключевые особенности

- **4 симуляционных отделения** с индивидуальной клинической механикой:
  - **ОРИТ (ICU):** экстренная реанимация, жёсткий таймер, исходы: стабилизация либо летальный исход.
  - **Приёмное отделение (Admission):** экстренная сортировка, первичная стабилизация и выбор маршрута госпитализации.
  - **Поликлиника (Outpatient):** амбулаторный приём без обратного отсчёта, витальные показатели по требованию, раздельный сбор анамнеза заболевания и жизни, формулирование диагноза и маршрутизация.
  - **Многодневный стационар (Stationary):** суточный цикл курации (утренний статус -> диагностика -> терапия -> оценка динамики) до достижения критериев выписки.
- **Математический движок детериорации в реальном времени:**
  - Динамический пересчёт 7 параметров жизнедеятельности: ЧСС, систолическое и диастолическое АД, ЧДД, SpO2, Шкала комы Глазго (ШКГ), уровень боли (ВАШ).
  - Валидированный индекс тяжести (SOFA-like, шкала 0–20 баллов).
  - Шаг итерации детериорации 30 секунд (15 секунд в стресс-режиме).
  - Матрица отклика на 52 лекарственных препарата и манипуляции с учётом латентного периода и терапевтического окна.
- **100% соответствие Клиническим рекомендациям Минздрава РФ:**
  - Каждый клинический сценарий верифицирован по актуальным протоколам и рубрикатору Минздрава России (cr.minzdrav.gov.ru).
  - Детерминированный алгоритмический дебрифинг: выявление фатальных врачебных ошибок, пропущенных обследований и необоснованной полипрагмазии.
- **Кроссплатформенность и нулевой порог входа:**
  - PWA-архитектура (Progressive Web Application): запуск в любом современном браузере без установки стороннего ПО.
  - Мгновенная загрузка интерфейса (<1.5 секунды) и стабильная работа даже при слабом интернет-соединении.
  - Адаптивность для ПК, ноутбуков, планшетов и смартфонов.

## Режимы симуляции

1. **Обычный режим (Case Select):** свободный выбор клинического случая по профилям и отделениям с фильтрацией.
2. **Случайный пациент (Random Case):** симуляция неотложного дежурства со случайной генерацией клинической ситуации.
3. **Стресс-режим (Stress Mode):** удвоенная скорость угасания витальных функций (шаг 15 сек), сокращённый лимит времени на принятие решений.
4. **Режим обучения (Curriculum Mode):** последовательный трек обучения: «Теоретический конспект -> Решение клинических задач -> Контрольный тест». Темы открываются по мере подтверждения компетенций.
5. **Обучающий режим (Learning Mode):** контекстные подсказки на каждом этапе с пояснением патофизиологического механизма.
6. **Режим контроля и аккредитации (Assessment Mode):** скрытые витальные маркеры, отключение подсказок, строгий учёт времени и действий для объективной экзаменационной оценки.

## Запуск и разработка

### Предварительные требования

- **Node.js:** версия 18.0 или новее
- **npm:** версия 9.0 или новее

### Установка зависимостей

```bash
npm install
```

### Запуск локального сервера разработки

```bash
npm run dev
```

Приложение будет доступно по адресу `http://localhost:3000`.

### Сборка для продакшена и предпросмотр

```bash
npm run build
npm run preview
```

### Проверка качества кода и валидация данных

Перед каждым коммитом в репозиторий запускается комплекс проверок:

```bash
# Проверка соответствия линтеру ESLint
npm run lint

# Автоматическая валидация всех клинических кейсов (связи, тесты, препараты)
node scripts/validate-cases.mjs

# Контроль чистоты интерфейса (строго векторные SVG-иконки)
node scripts/check-no-emojis.mjs
```
